# Post-game Statistics

![Post-game Statistics page](../../user-guide/images/MatchStatistics-PageDetails.webp)

Edit each player's post-game statistics here. The character names at the top are read-only and help you identify which character's statistics you are editing.

Once the SmartBP Module is installed correctly, an automatic recognition button appears at the top. Configure SmartBP to recognize Post-game Statistics automatically.
