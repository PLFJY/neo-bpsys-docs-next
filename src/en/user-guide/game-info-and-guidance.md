# Game Information and Guided Workflow

This feature saves game information and provides step-by-step guidance based on the rules stored in `GameRule.json`.

## How to use it

1. Choose whether to use BO3 mode. This button also changes the mode of several other features.
2. Set the game progress. Free Game Mode does not support step-by-step guidance.
3. Click **Start Guided Workflow**.

![Guided Workflow before starting](../../user-guide/images/GameInfoAndGuidance-MatchGuidanceNotStarted.webp)

**After following these steps, the window will look like this:**

![Guided Workflow running](../../user-guide/images/GameInfoAndGuidance-MatchGuidanceStarted.webp)

Click **Previous Step** or **Next Step** to navigate to the corresponding page and highlight the relevant controls according to the preset rules. Each step also **automatically** adjusts the countdown and activates the relevant pulsing highlights, without manual operation.

Click **Stop Guided Workflow** to stop the guidance manually.

For the rules, see the [Identity V Wiki](https://wiki.biligame.com/dwrg/%E6%AF%94%E8%B5%9B%E8%A7%84%E5%88%99).
