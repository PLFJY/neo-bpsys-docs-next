# クイックスタート

## インストール

### システム要件の確認
ソフトウェアを使い始める前に、以下の推奨環境を満たしていることを確認してください。

+ Windows 10 20H2 以降
+ 推奨構成は i5 13400F + RTX 3060 + 16GB メモリ（最低構成は i5 8300H + GTX 1060 + 8GB メモリ）*
+ [.NET 9.0 Desktop Runtime](https://dotnet.microsoft.com/ja-jp/download/dotnet/9.0) がインストールされていること（通常はインストーラーが自動的に処理します）

> *内蔵 GPU でも正常に動作しますが、配信担当者による使用は推奨しません。

## 基本操作

本ソフトウェアを初めて使う場合は、このガイドに従って使用方法を確認してください。

---

### 一、両チームの情報を設定する
ソフトウェアを起動したら、ウィンドウ左側の【チーム情報】をクリックします。各チームについてチーム名と選手名を入力し、チームロゴと選手の立ち絵（任意）をアップロードしたら、出場する全選手を【出場】に設定します（各チームのサバイバーとハンターの両方を設定してください）。
![チーム情報と出場選手の設定|500](/user-guide/images/设置队伍信息及上场选手.png)

ページの一番下には、現在出場している選手が表示されます。各サバイバー選手は、名前の後ろにある数字をクリックして位置を切り替えられます。

![出場選手の順番変更|500](/user-guide/images/修改上场选手顺序.png)

チーム情報をより簡単にインポートする方法は、[JSON からチーム情報をインポート](advanced/import-team-from-json.md)を参照してください。

---

### 二、試合形式を設定する
ソフトウェアのウィンドウで試合形式を BO5 または BO3 に設定できます。**この設定は[試合ガイド](backend/backend-game-info-and-guidance.md)やスコア計算など複数の機能に影響するため、正しく選択してください。**
![試合形式と試合ガイド領域の設定|500](/user-guide/images/设置赛制.png)

---

### 三、表示画面を起動する
ソフトウェア左側のページ選択エリアで[表示画面管理](backend/backend-fronted-manager.md)をクリックします。ここで各表示画面を開閉できます（通常はすべて開き、OBS などの配信ソフトで表示・非表示を管理することを推奨します）。**表示画面のレイアウトをカスタマイズする必要がない場合はデザインモードを有効にしないでください。誤って有効にしてコンポーネントを移動した場合は、【レイアウトをリセット】関連のボタンで復元できます。**
![表示画面管理|500](/user-guide/images/前台管理.png)

---

### 四、試合ガイドを開始する
本ソフトウェアの試合ガイドは、公式大会の BP ルールに基づいて設計されています。現在の試合進行（例：第1試合前半）を選択して【試合ガイドを開始】をクリックし、その後【次へ】を押してルールに従って操作します。【前へ】と【試合ガイドを終了】も使用できます。
![試合ガイド開始前|500](/user-guide/images/对局引导_未开始.png)

試合ガイドを開始すると、ガイドに従って BP を進められます。BP 中の各手順については、以下を参照してください。

+ [マップ BAN](backend/backend-map-bp.md)
+ [ハンター BAN](backend/backend-ban-hunter.md)
+ [サバイバー BAN](backend/backend-ban-survivor.md)
+ [キャラクター選択](backend/backend-pick-character.md)
+ [天賦・補助特質](backend/backend-talents-and-trait.md)

---

### 五、試合後データ
表示画面の[試合後データ画面](fronted/fronted-match-statistics.md)には、両チームの試合データを表示できます。試合後データ画面で各選手のデータを入力すると、入力内容が[試合後データ画面](fronted/fronted-match-statistics.md)に表示されます。
![試合後データ画面|500](/user-guide/images/赛后数据页面.png)

---

### 六、スコアを管理する
試合終了後、[スコアシステム](backend/backend-score-system.md)でスコアを入力・計算できます。スコアは[スコアコンポーネント](fronted/fronted-score.md)に同期されます。
![スコア管理|500](/user-guide/images/比分控制.png)

本ソフトウェアの試合結果による加点は公式大会と同じです。

| **試合結果** | **サバイバーチームの加点** | **ハンターチームの加点** |
| --- | --- | --- |
| 4人拘束 | 0 | 5 |
| 3人拘束 | 1 | 3 |
| 引き分け | 2 | 2 |
| 3人脱出 | 3 | 1 |
| 4人脱出 | 5 | 0 |

---

### 七、試合を終了する
1 試合が終了したら、【新しい試合（リセット）】をクリックして、その試合の BP 情報を消去します（マップ BP、グローバル BAN 記録、スコアなど、試合をまたいで保持される情報は残ります）。
