# BP 概要

![BP 概要](/user-guide/fronted/images/BP总览.png)

BP 概要と[マップ BP](fronted-map-bp.md)は、どちらも[表示画面管理ページ](../backend/backend-fronted-manager.md)のその他の小さなコンポーネントをクリックして開きます。

この機能は、1試合終了後にその試合の BP と小スコアを表示します。

このページの各部分の機能は以下のとおりです。

1. チームロゴ
2. チーム名
3. この試合で BAN されたハンター
4. 試合進行
5. この試合で BAN されたサバイバー
6. この試合のサバイバー側キャラクター選択
7. この試合の小スコア
8. ハンター側キャラクター選択
