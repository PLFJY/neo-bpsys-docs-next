# マップ BP

![マップ BP 画面|288](/user-guide/fronted/images/地图BP.png)

マップ BP と[BP 概要](fronted-bp-overview.md)は、どちらも[表示画面管理ページ](../backend/backend-fronted-manager.md)のその他の小さなコンポーネントをクリックして開きます。

このウィンドウには、[マップ BAN ページ](../backend/backend-map-bp.md)で BAN・選択したマップが表示されます。

このウィンドウの各部分の機能は以下のとおりです。

1. 選択されたマップ
2. チーム名
3. BAN されたマップ

---

新しいマップ BP 画面は以下のとおりです。
![MapBpV2](/user-guide/fronted/images/MapBpV2.png)

旧版との互換性を維持しながら、複数のマップを同時に BAN できます。詳しい操作方法は[マップ BAN](../backend/backend-map-bp.md)を参照してください。
