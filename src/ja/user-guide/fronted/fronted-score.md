# スコアコンポーネント

スコアコンポーネントは、ゲーム中に画面左上・右上へこの試合の小スコアと両チームの勝敗数を表示し、試合後には各ラウンドの小スコアを表示します。

本ソフトウェアは BO3 と BO5 の両方をサポートしています。切り替え方法は[試合情報と試合ガイド](../backend/backend-game-info-and-guidance.md)を参照してください。

以下はコンポーネントの表示例です。

![スコアコンポーネント（BO5 モード）](/user-guide/fronted/images/比分画面.png)

![スコアコンポーネント（BO3 モード）](/user-guide/fronted/images/比分画面_BO3.png)

> BO3 と BO5 のウィンドウコントロールはほぼ同じため、ここでは BO5 モードのコントロールだけを説明します。

各コントロールの機能は以下のとおりです。

1. 両チームのロゴ
2. 両チームの名前
3. 両チームの勝敗数
4. この試合の小スコア
5. 試合進行
6. 各試合進行の得点状況
7. 両チームの小スコア合計
