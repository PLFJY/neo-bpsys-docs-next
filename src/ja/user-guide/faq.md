# FAQ

このドキュメントには、ソフトウェアの使用中によくある問題と解決方法をまとめています。グループで質問したり issue を提出したりする前に、問題の解決方法がこのドキュメントにないか確認してください。

---

## 表示画面のコンポーネントがずれる
![表示画面のコンポーネントのずれ|425](/user-guide/images/前台组件错位.png)
1. システム設定を開く
2. 「システム - ディスプレイ」を開き、拡大縮小を 200% 以下に設定する（既定値を推奨）
3. ソフトウェアを再起動する

## デザインモードを開いても効果がない
これは現時点では解決できない基盤側の問題です。先に表示画面 UI を開いてからデザインモードを開いてください。
