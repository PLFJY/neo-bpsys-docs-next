# プラグインシステム

このページではソフトウェアのプラグインシステムを説明します。プラグインシステムを利用できない場合は、ソフトウェアを[2.0.0 以降](https://bpsys.plfjy.top/)に更新してください。

---
### プラグイン管理
![プラグイン管理](/user-guide/advanced/images/插件管理.png)上図はプラグイン管理画面です。ここでインストール済みのプラグインを管理できます。
【ファイルからプラグインをインストール】をクリックすると、新しいプラグイン（zip ファイル）をインストールできます。

詳しくは[プラグイン開発ドキュメント](/dev/plugin-dev-guide.md)を参照してください。
