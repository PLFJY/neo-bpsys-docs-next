# スコア管理

両チームのスコアを設定します。設定したスコアは各配信用ウィンドウに表示されます。

スコア管理には【フリーモード】と【標準対戦モード】があります。初期状態はフリーモードで、上部の対戦進行状況を選択すると標準対戦モードになります。

## 標準対戦モード {#标准对局模式}

![標準対戦モードのスコア管理](../../user-guide/images/ScoreSystem-ScorePageStandard.webp)

対戦終了後、該当するゲーム結果をクリックします。

![ゲーム結果の記録](../../user-guide/images/ScoreSystem-ScorePage.webp)

ボタンを押した時点の対戦状態が表に記録されます。

配信画面のスコアは、選択した対戦進行状況に応じて自動計算されます。

小スコアには次の3種類のフィールドがあり、使用する画面が異なります。

- 現在のゲームの累計小スコア：MinorHalfScore
    - BPメイン画面。
    - ゲーム内スコア。
- 現在のハーフの小スコア：CurrentMinorScore
    - 試合後の統計データ。
    - BP概要画面。
- 小スコア合計：TotalMinorScore
    - ゲーム内スコアの小スコア合計。
    - 総合スコア。

これらの英語のプロパティ名は、v3デザイナーでのフィールドバインディングに関わる重要な識別子です。3種類の集計範囲を区別することで、自作BPUIを正しく設定できます。

## フリーモード

![フリーモードのスコア](../../user-guide/images/ScoreSystem-ScorePageFreeGameMode.webp)

v2以前と同じ、加算と手動管理による方式です。上記の3種類の小スコアは区別しません。現在はこの方式を推奨していません。

ゲーム結果をクリックすると、以下のルールで加点されます。

| **ゲーム結果** | **サバイバーチームの加点** | **ハンターチームの加点** |
| --- | --- | --- |
| 4人脱落 | 0 | 5 |
| 3人脱落 | 1 | 3 |
| 引き分け | 2 | 2 |
| 3人脱出 | 3 | 1 |
| 4人脱出 | 5 | 0 |

1ゲーム終了後に【大スコアを集計】を手動でクリックすると、両チームの小スコアを比較し、大スコアを自動加算します。

### ゲーム内スコアを手動編集する

ポップアップで編集するスコアをクリックし、下部の操作領域で詳細を変更します。

![ゲーム内スコアの手動編集](../../user-guide/images/ScoreSystem-ManualScoreEdit.webp)

ここでの変更は、すべてのスコア表示に同期されます。

### 総合スコアを手動編集する

該当するスコア位置をクリックすると、下部で編集できます。通常はプリセットを選び、結果をクリックする方法をお勧めします。さらに下の手動編集欄は完全な手動操作用で、通常は使用する必要はありません。

![総合スコアの手動編集](../../user-guide/images/ScoreSystem-ManualEditGlobalScore.webp)
