# 配信用ウィンドウ管理

## 配信用ウィンドウ {#前台窗口}

![配信用ウィンドウ管理ページ](../../user-guide/images/FrontendManager-Page.webp)

配信画面の表示・非表示や、カスタム配信用ウィンドウを管理します。

上部の【すべてのループアニメーションを停止】は通常使用する必要はありません。呼吸アニメーションなどのループが停止しなくなった場合に使用します。

【v3配信画面デザイナーを開く】をクリックすると、別ウィンドウで配信画面を自由に編集できます。詳細は[v3配信画面デザイナー](advanced/v3-designer.md)を参照してください。

## レイアウトパッケージ

インポートした配信画面レイアウトパッケージのインポート、エクスポート、削除、コピー作成を行います。

![レイアウトパッケージタブ](../../user-guide/images/FrontendManager-LayoutPackageTab.webp)

v3エディターで組み込みレイアウトパッケージを変更すると、自動でコピーが作成され、その後はコピーで作業を続けます。

v2以前の古いbpuiパッケージもそのままインポートでき、フォーマットが自動更新されます。ただし、完全な再現は保証されません。変換に問題がある場合は開発チームへ報告してください。
