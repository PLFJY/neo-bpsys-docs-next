# キャラクターBAN

[BP表示画面](fronted-manager.md#前台窗口)に表示するBAN済みキャラクターを設定します。

サバイバーBANとハンターBANの両方をこのページで説明します。

![ハンターBAN](../../user-guide/images/BanCharacter-HunBanSelection.webp)

![サバイバーBAN](../../user-guide/images/BanCharacter-SurBanSelection.webp)

ハンターには当該ゲームのBAN枠が2枠、グローバルBAN枠が4枠あります。サバイバーには当該ゲームのBAN枠が4枠、グローバルBAN枠が16枠あります。

## キャラクター選択欄 {#角色选择器}

キャラクター選択欄は、以下の要素で構成されています。

- 入力可能なドロップダウン（コンボボックス）。
- 確定ボタン。
- アイコンのプレビュー。

ドロップダウンでキャラクターを検索・選択します。中国語の正式名称、ピンイン全体、ピンインの頭文字で検索できます。キーワードを入力してSpaceを押すと検索されます。見つからない場合は、次のメッセージが表示されます。

![キャラクター検索失敗](../../user-guide/images/BanCharacter-CharaSearchFailed.webp)

見つかったら**TabまたはEnter**で確定します。Enterは2回押す必要があるため、Tabをお勧めします。プレビューに該当キャラクターのアイコンが表示されれば選択完了です。配信画面のBAN枠は、このプレビューと常に一致します。**確定前のドロップダウンの選択は配信画面に同期されません。** 現在表示されているキャラクターは、プレビューで確認してください。

例：白黒無常（宿伞之魂）は、以下のキーワードで検索できます。

- 宿伞之魂
- 宿伞
- sszh
- ss

ドロップダウンだけの簡易版もあり、[キャラクターPICK](pick-character.md)ページのグローバルBAN履歴で使用されています。

> ガードNo.26は `bb` で検索できます。中国語の愛称「邦邦」には対応していないため、短い `bb` を使用してください。

## 当該ゲームのBAN／グローバルBAN {#当局全局禁用}

【当該ゲームのBAN】領域で、そのゲームでBANするハンターを指定します。確定したキャラクターは配信画面に同期されます。

## BAN枠数の設定

BAN枠数はカスタマイズできます。無効にした枠は配信画面で鍵のアイコンとして表示されます。ロック時の見た目はv3エディターでも変更でき、詳細はデザイナーの説明で紹介します。
