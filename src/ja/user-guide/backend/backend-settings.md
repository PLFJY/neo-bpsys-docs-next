# 設定ページ

このページでは、ソフトウェアの個人設定、作者情報、連絡先、バージョン、オープンソースライセンス、支援方法などの各種情報の表示、ソフトウェアの更新を行います。

![ソフトウェア情報エリア](/user-guide/backend/images/软件信息区域.png)

ここではソフトウェアのバージョン、使用しているオープンソースライブラリ、ソフトウェアの更新を確認できます。

現在、ソフトウェアの更新では中国国内から利用できる3つのダウンロード元をサポートしています。4つ目の空のダウンロード元は元サイト（GitHub）からダウンロードします。隣にはテスト版をダウンロードするスイッチがあります。現在のテスト段階では既定でオンですが、正式版では既定でオフになります。

![ショートカットエリア](/user-guide/backend/images/快捷入口区域.png)
【表示画面の設定ファイルがあるフォルダーを開く】は、表示画面のレイアウトを手動で変更するのに便利です。

【試合ファイルの出力フォルダーを開く】は、保存された試合情報を確認するのに便利です。

【ログフォルダーを開く】は、バグを報告するときに開発者へログを提供するために使用します。

![表示画面 UI のカスタマイズエリア](/user-guide/backend/images/前台UI个性化区域.png)

最新版のソフトウェアでは、各表示ウィンドウの背景や各領域の文字のフォント、サイズ、色、太さなどを細かくカスタマイズできます。

WeChat Pay の QR コードをスキャンして開発を支援できます。ご支援に心より感謝します！
