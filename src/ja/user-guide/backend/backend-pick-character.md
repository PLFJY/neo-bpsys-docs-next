# キャラクター選択

このページでは、両チームが選択したキャラクターと全試合共通 BAN の記録を管理します。以下はサバイバー選択部分です。

![サバイバー選手のキャラクター選択](/user-guide/backend/images/求生者角色选择.png)

操作方法は[ハンター BAN](backend-ban-hunter.md)の BAN 方法と同じです。

![ハンター選手のキャラクター選択](/user-guide/backend/images/监管者角色选择.png)

上記と同様に操作します。

![待機枠の切り替え](/user-guide/backend/images/待选择框开关.png)

指定された選手のキャラクター選択順になったら、待機枠を有効にします。

![全試合共通 BAN 記録](/user-guide/backend/images/全局禁选记录.png)

全試合共通 BAN 記録では、各チームが次にその陣営を担当するときに全試合共通 BAN に入るキャラクターを記録します。サイド交代時には自動的に全試合共通 BAN に適用されます。キャラクターを手動で記録欄に入力してください（次の試合から有効になります）。
