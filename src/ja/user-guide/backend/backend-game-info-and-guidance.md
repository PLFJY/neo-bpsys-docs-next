# 試合情報と試合ガイド

この機能は、試合情報を保存し、GameRule.json に保存された大会ルールに従って手順を案内します。

#### 使用方法
1. 必要に応じて BO3 モードを選択する（このボタンは、この機能以外の複数の機能のモードも決定します）
2. 試合の進行を設定する（フリーマッチでは手順ガイドを使用できません）
3. 【試合ガイドを開始】をクリックする

![試合ガイド開始前](/user-guide/backend/images/对局引导_未开始.png)

**上記の手順に従うと、ウィンドウは次のようになります。**

![試合ガイド開始後](/user-guide/backend/images/对局引导_已开始.png)

【前へ】または【次へ】をクリックしてあらかじめ設定されたルールに従ってページを切り替えるか、【試合ガイドを終了】をクリックして手動で進行できます。対応する手順では、タイマーや対応する呼吸灯も自動的に調整されるため、手動操作は不要です。

ルールの詳細は[第五人格 WIKI](https://wiki.biligame.com/dwrg/%E6%AF%94%E8%B5%9B%E8%A7%84%E5%88%99)を参照してください。
