# マップ BAN

このページでは、マップ BP ウィンドウに表示する選択済み・BAN 済みのマップを設定します。

![マップ選択](/user-guide/backend/images/地图选择.png)

![マップ BAN 部分](/user-guide/backend/images/地图禁用.png)

すべてのランク戦マップを選択・BANできます。使用方法は選択または BAN したいマップをクリックするだけです（~~将来は複数選択に対応予定~~[v1.1.0.9483](https://github.com/PLFJY/neo-bpsys-wpf/releases/tag/v1.1.0.9483)から対応済み）。

現在は新旧両方のマップ BP ルールと、それに対応する表示画面をサポートしています。詳しくは[マップ BP](../fronted/fronted-map-bp.md)を参照してください。

---

MapBpV2 の新ルールでは、以下の機能を利用できます。

待機枠の呼吸灯：
BAN されていないマップに呼吸灯を表示します（新マップ BP）。
![新マップ BP の呼吸灯オフ](/user-guide/backend/images/新地图BP前台.png) ![新マップ BP の呼吸灯オン](/user-guide/backend/images/新地图BP前台开呼吸灯.png)

陣営選択結果の表示：
各マップを BAN・選択したチーム名と陣営を表示します。
![新マップ BP の陣営選択結果](/user-guide/backend/images/新地图BP前台开阵营选择结果.png)
