# 天賦・補助特質

このページでは、トランジション画面に表示する両チームの天賦とハンターの補助特質を設定します。

#### 天賦セレクター
ここでもカスタムコントロールを使用します。天賦セレクターは4つの ToggleButton で構成されています（適切な日本語訳が分かりませんが、選択できれば問題ありません）。天賦の位置はゲーム内と完全に同じなので、ゲームと同じ感覚で選択できます。

![サバイバーの天賦選択](/user-guide/backend/images/求生者天赋.png)

![ハンターの天賦選択](/user-guide/backend/images/监管者天赋.png)

#### 補助特質の選択
ゲーム内の大会モードでは観戦席からハンターが持つ補助特質を確認できないため、本ソフトウェアではハンターの補助特質を表示するかどうかを選択できます。ハンター選手が使用する補助特質をクリックしてください。

![ハンターの補助特質選択](/user-guide/backend/images/监管者技能.png)
