# タイマー

![カウントダウン](/user-guide/backend/images/倒计时.png)

この機能は、表示ウィンドウの[BP 画面](../fronted/fronted-bp.md)にタイマーを表示します。タイマーの動作中は BP 画面の「VS」が残り秒数に置き換わり、カウントダウンが終了するか手動で停止すると「VS」に戻ります。

#### 使用方法
1. ドロップダウンまたはコントロールを左クリックして秒数を設定する
2. 【開始】ボタンをクリックする
3. 停止する場合は【停止（VS に戻す）】をクリックするか、カウントダウンが0になるまで待つ

> <font color="#595959">右側の【プレビュー】には、現在 BP 画面の「VS」の位置に表示される内容が表示されます。</font>
