# チーム情報の編集

このページでは、チーム名、チームロゴ、出場選手などのチーム情報を設定します。

![チーム情報と出場選手の設定](/user-guide/backend/images/设置队伍信息及上场选手.png)

上図はチーム情報の入力ページです（アウェイ側も同様です）。

各チーム情報を入力すれば使用できます（立ち絵は任意です）。

【出場】をクリックして選手を出場させます（1チームのハンター選手とサバイバー選手を同時に出場させることもできます。ソフトウェアがサイドに応じて自動調整します）。

また、【JSON ファイルからインポート】ボタンを使って、[JSON からチーム情報を一括インポート](../advanced/import-team-from-json.md)できます。

両チームの出場選手を設定したら、下図のボタンで選手の表示順を変更できます（選手名の後ろにある数字をクリックすると、その選手と指定位置の選手が入れ替わります）。

![出場選手の順番変更](/user-guide/backend/images/修改上场选手顺序.png)
