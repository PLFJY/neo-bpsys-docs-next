# カウントダウンタイマー

![カウントダウン](../../user-guide/images/Countdown-Page.webp)

[BP表示画面](fronted-manager.md#前台窗口)にタイマーを表示する機能です。動作中は「VS」が残り秒数に置き換わり、カウントダウンが終了するか手動で停止すると「VS」に戻ります。

#### 使用方法

1. ドロップダウン、またはコントロールの左クリックで秒数を設定します。
2. 【開始】をクリックします。
3. 【停止（VSに戻す）】をクリックするか、残り時間が0になるまで待ちます。

> <span style="color: #595959">右側の【プレビュー】には、現在のBP表示画面の「VS」位置に表示されている内容が表示されます。</span>

通常は[ステップガイド](game-info-and-guidance.md)に合わせて自動で開始・停止するため、手動調整は不要です。
