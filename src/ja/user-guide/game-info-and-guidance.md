# 対戦情報と進行ガイド

対戦情報を保存し、`GameRule.json` に記録された大会ルールに従ってステップガイドを行う機能です。

## 使用方法

1. BO3モードを使用するか選択します。このボタンは、ほかの複数の機能のモードにも影響します。
2. 対戦進行状況を設定します。フリーモードはステップガイドに対応していません。
3. 【対戦進行ガイドを開始】をクリックします。

![開始前の対戦進行ガイド](../../user-guide/images/GameInfoAndGuidance-MatchGuidanceNotStarted.webp)

**上記の手順を行うと、次のような画面になります。**

![開始後の対戦進行ガイド](../../user-guide/images/GameInfoAndGuidance-MatchGuidanceStarted.webp)

【前のステップ】または【次のステップ】をクリックすると、プリセットルールに従って該当ページへ移動し、操作領域が強調表示されます。カウントダウンの調整や対応する呼吸アニメーションの開始も**自動**で行われるため、手動操作は不要です。

手動で終了する場合は、【対戦進行ガイドを終了】をクリックします。

ルールの詳細は[第五人格WIKI](https://wiki.biligame.com/dwrg/%E6%AF%94%E8%B5%9B%E8%A7%84%E5%88%99)を参照してください。
