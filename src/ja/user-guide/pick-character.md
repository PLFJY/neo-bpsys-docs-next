# キャラクターPICK

両陣営のPICKしたキャラクターとグローバルBAN履歴を記録するページです。

![キャラクターPICKページ](../../user-guide/images/PickCharacter-PickPage.webp)

## 各陣営の出場キャラクターを選択する

サバイバーの選択欄が4つ、ハンターの選択欄が1つあります。各サバイバー選択欄の上部には、その枠の選手名を表示する読み取り専用欄があり、キャラクター割り当て時の照合に使えます。

操作方法は[キャラクター選択欄](ban-character.md#角色选择器)と同じです。

各サバイバー選択欄の下には、キャラクター割り当ての切り替えボタンがあります。[チーム情報](team-info.md#修改选手顺序)の選手入れ替えボタンと同様に、数字をクリックすると、その位置のサバイバー側の選手と使用キャラクターを入れ替えます。

⚠️ [キャラクター選択欄](ban-character.md#角色选择器)で説明したとおり、配信画面の表示はプレビューと一致します。入れ替え後にドロップダウンの名前が一致しなくても正常です。不具合として報告する必要はありません。

## グローバルBAN履歴

![グローバルBAN履歴](../../user-guide/images/PickCharacter-GlobalBanRecordDetails.webp)

各チームが**次に同じ陣営を担当するとき**にグローバルBANとなるキャラクターを記録し、陣営切り替え時に自動適用します。

ここでは簡易版の[キャラクター選択欄](ban-character.md#角色选择器)を使用しており、検索機能はすべて同じように使えます。

動作は以下のとおりです。

- 自動記録を有効にすると、現在の対戦進行状況と各チームの陣営に応じて、PICKしたキャラクターをそのチームのグローバルBAN履歴に記録します。例：

    第1ゲーム前半戦で**ホームチーム**がサバイバーを担当し、占い師、オフェンス、祭司、傭兵をPICKした場合、上図のように【**ホームチーム**のグローバルBAN履歴】の1～4枠へ自動入力されます。

    第2ゲーム後半戦で**アウェイチーム**がサバイバーを担当して4名をPICKすると、【**アウェイチーム**のグローバルBAN履歴】の1～4枠へ自動入力されます。
- そのチームが次に同じ陣営を担当すると、[キャラクターBAN](ban-character.md#当局全局禁用)のグローバルBAN欄へ自動入力されます。次の操作で自動入力が実行されます。
    - 陣営切り替え。
    - 対戦進行ガイドの開始。
    - 【次のゲーム（リセット）】をクリックして【はい】を選ぶ、または【リセットのみ】を選ぶ。
