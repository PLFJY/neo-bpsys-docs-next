# チーム情報の編集

チーム名、チームロゴ、出場選手などを設定するページです。

## チーム情報と出場選手の設定

![チーム情報と出場選手の設定](../../user-guide/images/TeamInfo-TeamInfoPage.webp)

上図はチーム情報の入力ページです。アウェイチームも同じ手順で設定します。

各項目にチーム情報を入力してください。

【出場に設定】をクリックすると、その選手を出場状態にできます。同時に出場できるのはサバイバーが4名、ハンターが1名までです。別の選手を出場させる場合は、まず同じ陣営の出場選手を少なくとも1名【控えに変更】してください。

【JSONファイルからインポート】を使うと、[チーム情報を一括インポート](advanced/import-team-from-json.md)することもできます。

## 選手の順番を変更する {#修改选手顺序}

両チームの出場選手を設定したら、下図のボタンで表示順を変更できます。

選手名の後ろにある数字をクリックすると、指定した位置の選手と入れ替わります。

![出場選手の順番を変更](../../user-guide/images/TeamInfo-ReorderActivePlayers.webp)
