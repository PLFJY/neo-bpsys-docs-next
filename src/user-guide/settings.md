# 设置页面

本页面的功能是针对软件进行个性化设置以及显示本软件的各类信息，如作者信息、联系方式、版本号、开源协议、赞助方式等，以及软件的更新信息。

## 软件基础信息

![软件信息区域](images/Settings-SoftwareInfoSection.webp)

在这里可以查看软件版本、使用的各类开源代码库以及进行软件更新。

软件的更新目前支持 11 个国内也许可用的下载源，第 12 个空的下载源是从源站 (Github) 下载，旁边还有一个下载预览版的开关，现在测试阶段这个开关默认开启，正式版后此开关会默认关闭

## 选项开关

![选项开关](images/Settings-OptionsSwitch.webp)

### 经典模式

开启经典模式的开关之后，界面会变成如同 bp-sys-wpf ≤ 2.6 版本的全平铺界面，是另一种使用方式，但是对局引导在这里可能发挥不到很好的效果，同时开发团队也不会对这个界面做更深入的支持，如果遇到问题及时向开发团队反馈

![经典模式](images/Settings-ClassicMode.webp)

### 关联 .bpui 文件

开启后可以让 .bpui 文件被双击打开，打开后会自动导入布局包当中

![alt text](images/Settings-BpuiAutoImport.webp)

### 关闭页面切换动画

如果你觉得这个页面切换动画很拖沓，可以在这里关闭

## 路径调整

![路径调整](images/Settings-EditPath.webp)

在这里可以修改智慧 BP 的安装目录和对局文件的输出目录，避免占用 C 盘的空间

## 快捷入口

![快捷入口区域](images/Settings-QuickAccessSection.webp)

【打开前台配置文件所在目录】的作用是便于用户手动修改前台布局。

【打开对局文件输出目录】的作用是使用户查看保存的对局信息‍更方便。

【打开日志目录】 的作用是便于用户在反馈bug时向开发者提供日志。（现已移动到了调试选项的卡片当中）
