Remarks

内置窗口或未关联插件包的窗口直接使用局部窗口标识； 插件窗口使用 plugin:{PackageId}/{LocalId} 形式，与 FrontedV3LayoutWindowPathHelper 的 CanonicalWindowId 约定一致。

EnsureValidWindowLocalId(string)

校验窗口局部 ID 是否可作为 Canonical ID 的安全片段。

public static void EnsureValidWindowLocalId(string id)

Parameters

id string

待校验的窗口局部 ID。

Remarks

该校验不要求 GUID；允许任意不会破坏 Canonical ID 结构、路径解析或比较语义的稳定字符串。 插件 XAML 窗口的 Canonical ID 为 plugin:{PackageId}/{LocalId}， 其中 / 是结构分隔符，因此 LocalId 自身不得包含 /。

Exceptions

ArgumentException

当 ID 为空/空白、含前后空白、含路径分隔符（/、</code>）、含冒号（:）或含控制字符时抛出。
