v3 前台控件几何操作的抽象接口，由 Designer 的 Move/Resize/Snap/Clamp/Undo 统一调用。

public interface IFrontedV3GeometryTarget

Remarks

该接口在 Phase 2 引入，用于将根控件的几何写入与视觉更新从 Designer ViewModel 中解耦。 Phase 6 完成去特化后，所有 Move/Resize 只调用本接口，不再通过 if (config is BorderedImage...) 等类型分支选择几何实现。

实现负责：

  • 将几何值写入当前 FrontedControlConfigBase（根级字段 Left/Top/Width/Height）。
  • 调用宿主 FrontedV3ControlHost.ApplyRootLayout 同步视觉。

实现不得修改 ControlType、BehaviorGuid、ZIndex、 Visibility、GaussianBlur 等非几何根级字段。
