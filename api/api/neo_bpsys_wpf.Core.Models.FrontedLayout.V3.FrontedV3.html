v3 前台控件的 XAML 附加属性入口，提供 PartIdProperty 用于在 XAML 中标记 Part Visual。

FrontedV3

Remarks

XAML 用法： 

<Border fronted:FrontedV3.PartId="Logo">
    <Image />
</Border>

与 C# 特性 [FrontedV3PartVisual("Logo")] 等价，两种声明方式解析后映射到同一个 Part。

Visual 发现器（FrontedV3PartVisualResolver）同时扫描 XAML 附加属性与 C# 特性， 缺失或重复的 Visual 输出诊断日志，不崩溃 Designer。
