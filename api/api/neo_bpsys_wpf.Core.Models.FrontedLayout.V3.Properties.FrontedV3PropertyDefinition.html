Remarks

该类型是属性的"运行时定义"，同时携带 OptionsPath（逻辑路径）、 Storage（存储访问器）、PropertyType（强类型）和 Metadata（元数据）。

GetValue(FrontedControlConfigBase) / SetValue(FrontedControlConfigBase, object?) 是 Options 视图与 Designer 属性网格的唯一读写入口： 读取时调用 GetValue(FrontedControlConfigBase) 取原始值，再通过 FrontedV3ValueConverter 转换为 PropertyType；写入时反向转换后调用 SetValue(FrontedControlConfigBase, object?)。Options 视图不缓存独立值。
