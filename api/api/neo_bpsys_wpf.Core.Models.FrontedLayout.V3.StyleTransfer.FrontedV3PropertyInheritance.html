v3 前台控件属性的继承模式，决定子控件如何从父控件获取属性值。

public enum FrontedV3PropertyInheritance

Fields

CopyFromParentOnCreate = 2

创建时从父控件复制。子控件在创建时从父控件复制值，之后独立持有，不再动态关联父控件。

LockedToParent = 3

锁定到父控件。子控件的值始终等于父控件的值，任何对子控件的 override 写入都会被拒绝。

None = 0

不继承。子控件独立持有自己的值，不读取父控件。

ParentFallback = 1

父回退模式。子控件有 override 时使用 override，没有时动态回退到父控件同 OptionsPath 的值。

该模式每次读取时动态判断子控件是否有 override，不缓存 fallback 值。

Remarks

支持四种继承模式：

  • None：不继承，子控件独立持有自己的值。
  • ParentFallback：动态读取——子控件有 override 时使用 override， 没有时回退到父控件同 OptionsPath 的值。该模式不在创建 View 时复制 fallback 值， 而是每次读取时动态判断。
  • CopyFromParentOnCreate：创建时从父控件复制值，之后子控件独立持有。 复制后与父控件不再有动态关联。
  • LockedToParent：锁定到父控件值，拒绝 override。子控件的值始终等于父控件的值， 任何对子控件的写入都会被拒绝。

ParentFallback 的关键约束：必须动态读取。不得在创建 View 时复制一份 fallback 值， 否则父控件后续修改无法反映到子控件。
