v3 前台控件属性的语义分类，驱动 StyleTransfer 的传播范围与 PropertyGrid 的分组。

public enum FrontedV3PropertySemantic

Fields

Appearance = 0

视觉样式属性（颜色、字体、边框、图片路径等），默认参与 StyleTransfer 传播。

Behaviors = 4

行为设置（BehaviorGuid 等），仅当 profile 显式开启时传播。

DataIdentity = 1

数据身份字段（MapKey、TeamType、BindingPath、ControlName 等），永不参与传播。

传播数据身份字段会导致控件指向错误的数据源，因此该语义的属性在任何 profile 下都不会被传播。

Effects = 5

视觉效果（高斯模糊等），仅当 profile 显式开启时传播。

Other = 6

未分类属性，不参与传播。

PartLayout = 3

固定内部部件几何（Part 的 X/Y/Width/Height），仅当 profile 显式开启时传播。

RootSize = 2

根控件尺寸（Width/Height），仅当 FrontedV3StyleTransferProfile 显式开启时传播。

Remarks

语义分类决定属性在 StyleTransfer 操作中的行为：

  • Appearance：视觉样式属性（颜色、字体、边框等），默认参与传播。
  • DataIdentity：数据身份字段（MapKey、TeamType、BindingPath、ControlName 等），永不传播。
  • RootSize：根控件尺寸（Width/Height），仅当 profile 显式开启时传播。
  • PartLayout：固定内部部件几何（X/Y/Width/Height），仅当 profile 显式开启时传播。
  • Behaviors：行为设置，仅当 profile 显式开启时传播。
  • Effects：视觉效果（模糊等），仅当 profile 显式开启时传播。
  • Other：未分类属性，不参与传播。

根级保留字段（Left/Top/ZIndex 等）由 FrontedV3ReservedFields 管理， 不会注册为属性，因此不需要单独的语义分类。
