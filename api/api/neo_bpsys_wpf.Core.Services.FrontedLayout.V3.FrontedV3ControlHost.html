Remarks

结构统一为 Canvas → FrontedV3ControlHost → FrontedV3ControlBase。 Host 是 v3 控件路径中唯一被直接加入 Canvas 的元素，所有根级属性都由 Host 拥有， 包装的 Control 只负责矩形区域内的视觉内容，不得设置自己的 Canvas 坐标。

Host 唯一负责以下根属性：

  • System.Windows.Controls.Canvas.LeftProperty、System.Windows.Controls.Canvas.TopProperty
  • System.Windows.Controls.Panel.ZIndexProperty
  • System.Windows.FrameworkElement.Width、System.Windows.FrameworkElement.Height
  • System.Windows.UIElement.Visibility
  • 视觉效果链（高斯模糊、阴影、发光）—— 通过 Border 包装实现 Effect 树
  • BehaviorGuidProperty 标记
  • IsGeneratedControlProperty 运行时生成标记
  • Designer 选中与根 Move/Resize（通过 neo_bpsys_wpf.Core.Services.FrontedLayout.V3.Geometry.RootControlGeometryTarget）
  • 错误占位（ShowError(Exception)）

本 Host 是所有 v3 前台控件的唯一根布局实现。

Remarks

该方法是 v3 控件创建路径的错误边界，覆盖以下失败场景：

  • 控件构造函数失败（含 XAML InitializeComponent 失败）。
  • InitializeFrontedV3 调用失败（含 Binding 初始化、服务解析失败）。

控件通过 CreateInstance(IServiceProvider, Type, params object[]) 创建，支持构造函数依赖注入； 随后直接调用 InitializeFrontedV3(FrontedV3ControlContext) 完成上下文注入。

根布局（ApplyRootLayout()）在创建控件之前应用，确保无论成功还是失败 Host 都具备 Left/Top/Width/Height/ZIndex/Visibility、 BehaviorGuid 与 IsGeneratedControl 标记。失败路径的错误占位同样可被 FrontedRenderer 通过 IsGeneratedControl 识别并清理，避免重复堆积。

失败时：Runtime 记录 warning 并显示安全占位；Designer 通过 IsDesignerPreview 显示带 Designer 标识的错误占位；原 Config 保留，不写默认值覆盖。

Exceptions

ArgumentNullException

当 context 为 null 时抛出。
