固定 Part 的几何信息，坐标相对于父 Control（不是 Canvas 绝对坐标）。

public sealed class FrontedV3PartGeometry
Inheritance
object
FrontedV3PartGeometry

Remarks

Part 几何与根控件几何不同：根控件使用 Canvas 绝对坐标（Left/Top）， Part 使用相对于父 Control 的坐标（X/Y）。

Width/Height 为 null 时表示该维度无显式尺寸 （由父 Control 布局槽决定）。
