v3 前台控件 StyleTransfer 的每次操作传播 profile，描述本次操作实际传播哪些语义。

public sealed class FrontedV3StyleTransferProfile
Inheritance
object
FrontedV3StyleTransferProfile

Remarks

Profile 是操作选择（per-operation selection），描述本次 Apply Parent Style / Peer Transfer 操作实际要传播哪些语义。实际传播需要同时满足两个条件：

  • 属性语义被 FrontedV3PropertyTransfer（能力声明）允许。
  • 属性语义被本 Profile 选中。

默认 profile 仅传播 Appearance。 RootSize、PartLayout、 Behaviors、Effects 需要显式开启才会传播。

DataIdentity 在任何 profile 下都不会传播， 因为 CanTransfer(FrontedV3PropertySemantic) 对 DataIdentity 永远返回 false。
