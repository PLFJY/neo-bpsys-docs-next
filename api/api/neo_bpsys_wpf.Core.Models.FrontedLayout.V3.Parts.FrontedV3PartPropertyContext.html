Remarks

当用户在 Designer 中选中某个固定 Part 时，属性网格根据该上下文构建编辑行， 编辑操作通过 PartDefinition 的存储访问器写回 Config。

该上下文不缓存独立值，所有读写最终作用于 Config 的现有字段。
