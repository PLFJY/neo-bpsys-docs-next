v3 前台控件的运行时上下文，由宿主在创建控件时提供。

FrontedV3ControlContext

Remarks

该上下文替代旧 FrontedControlBuildContext 中面向 v3 控件的部分， 但在 Phase 1 期间两者并存：旧链路继续使用 FrontedControlBuildContext， 新 v3 控件链路使用本类型。

上下文携带控件运行所需的服务、所属窗口/Canvas 信息、当前 Config 实例， 以及由属性 Schema 构建的 Options 动态代理视图。控件 XAML 通过绑定 {Binding Options.Appearance.TextColor} 等路径读写属性，最终委托到对应 IFrontedV3StorageAccessor。
