可选的前台画布增量渲染能力。

public interface IFrontedIncrementalRenderer

Remarks

适合属性编辑、单个控件增删等局部变更；调用方应在局部刷新失败时回退 IFrontedRenderer 的完整渲染。完整重建仍适用于画布/窗口切换、 布局整体替换和需要重建名称作用域的场景。

所有方法必须在拥有 canvas 的 WPF Dispatcher 线程上调用；实现应校验 canvas、config、context 非空。批量方法的 controlNames 只枚举一次，重复名称按一个处理；返回数量小于去重后的名称数量表示部分失败。
