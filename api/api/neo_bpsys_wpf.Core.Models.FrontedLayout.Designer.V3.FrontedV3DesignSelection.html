Designer 的统一选中目标，可表示根控件、固定 Part 或 PartCollection 集合项三类选中。

public sealed class FrontedV3DesignSelection
Inheritance
object
FrontedV3DesignSelection

Remarks

Phase 6 Designer 去特化的核心契约：Designer 只维护 FrontedV3DesignSelection? SelectedTarget，所有 Move/Resize/Snap/Clamp/Undo 只调用 GeometryTarget，所有属性编辑只读写 Properties。

三类 FrontedV3DesignSelectionKind 对应三种 selection：

  • Root：根控件属性，由 RootControlGeometryTarget 驱动几何。
  • FixedPart：固定 Part 属性，由 FixedPartGeometryTarget 驱动几何。
  • CollectionItem：PartCollection 集合项属性，由 CollectionItemGeometryTarget 驱动几何。

该类型不缓存独立属性值；属性读写都通过 Properties 中的 Storage 完成以保持单一事实来源。
