固定 Part 的已解析定义，描述 Part 的标识、存储位置与操作能力。

public sealed class FrontedV3PartDefinition
Inheritance
object
FrontedV3PartDefinition

Remarks

Part 是控件内部固定区域的抽象（如 BorderedImage 的内层 Image、MapV2 的 TeamName 部件）。 每个 Part 通过 Id 标识，几何值通过 XStorage/YStorage/ WidthStorage/HeightStorage 读写到 Config 的现有字段。

存储访问器为 null 时表示该维度不可持久化（如 BorderedImage 内层 Image 的 X/Y 由对齐方式决定，不存储到 Config）。

Capabilities 决定 Designer 中允许对该 Part 执行的操作类型； IFrontedV3GeometryTarget 实现必须遵守能力约束。

Remarks

当 Part 在 Designer 中被选中时，FrontedV3DesignSelectionBuilder.BuildFixedPartSelection 会将几何属性（XStorage/YStorage/WidthStorage/HeightStorage 对应的属性）与该列表中的外观属性合并，作为选中目标的 Properties 返回。

该列表中的 FrontedV3PropertyDefinition 必须已配置好 Storage（通常使用 FrontedV3Storage.ClrProperty 读写父 Config 的 CLR 属性， 或使用 FrontedV3Storage.CollectionItemProperty 读写 Part 在父 Config 列表中的项属性）， 因为固定 Part 不需要 itemKey 参数。

默认 null 表示该 Part 只支持几何编辑（如 MapV2 的内部部件、BorderedImage 的 Image）。
