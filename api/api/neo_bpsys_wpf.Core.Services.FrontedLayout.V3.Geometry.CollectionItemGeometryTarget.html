PartCollection 集合项的几何操作目标，将 Designer 的 Move/Resize 通过集合项的 Storage 写入 Config。

public sealed class CollectionItemGeometryTarget : IFrontedV3GeometryTarget
Inheritance
object
CollectionItemGeometryTarget
Implements
IFrontedV3GeometryTarget

Remarks

该实现遵守 FrontedV3PartCapabilities 约束：

  • CanMove 为 false 时 MoveTo(double, double) 不写入。
  • CanResize 为 false 时 ResizeTo(double, double, double?, double?) 不写入。

几何值通过集合项的 CLR 属性（X/Y/Width/Height）读写到 Config 的现有集合字段， 不直接操作 Visual 的尺寸。坐标相对于父 Control，而非 Canvas 绝对坐标。

构造时通过 CollectionGetter 与 ItemKeySelector 创建绑定到指定项键的存储访问器。
