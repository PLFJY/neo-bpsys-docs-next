Remarks

该注册表是前台控件的唯一正式注册表，收集通过 AddFrontedV3Control<T>() 或 AddBuiltInFrontedV3Control<TControl,TConfig>() 注册的所有控件。

重复的 Canonical Control Type 在构造时抛出 FrontedLayoutConfigException。
