Designer 子控件（Part/CollectionItem）的命中框与装饰器信息。 由 ViewModel 构造，供 View 创建透明 hitbox、selection adorner 与 resize handles。

public sealed class DesignerChildTargetInfo
Inheritance
object
DesignerChildTargetInfo

Remarks

几何值（Left/Top/Width/Height） 相对于父控件，View 需要叠加父控件的画布坐标得到绝对位置。 CanMove/CanResize 来自 FrontedV3PartCapabilities， View 根据能力决定是否显示移动光标与缩放手柄。
