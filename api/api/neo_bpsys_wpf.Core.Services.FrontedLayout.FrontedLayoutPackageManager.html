Class FrontedLayoutPackageManager

Namespace
neo_bpsys_wpf.Core.Services.FrontedLayout
Assembly
neo-bpsys-wpf.Core.dll

前台布局包管理器，负责布局包的安装、激活、删除、复制以及包列表查询等功能。 内置包（PackageId = "builtin"）为只读的默认布局方案，本地包（PackageId = "local"）为不可激活的资源包。
