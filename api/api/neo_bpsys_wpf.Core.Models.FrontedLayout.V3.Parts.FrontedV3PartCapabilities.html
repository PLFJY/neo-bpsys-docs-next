固定 Part 的操作能力，决定 Designer 中允许对该 Part 执行的几何操作类型。

public sealed class FrontedV3PartCapabilities
Inheritance
object
FrontedV3PartCapabilities

Remarks

能力是显式约束：CanMove 为 false 时 Designer 不得调用 MoveTo(double, double)； CanResize 为 false 时 Designer 不得调用 ResizeTo(double, double, double?, double?)。

典型用法：

  • BorderedImage 内层 Image：Resize（只允许 Resize，不允许 Move）。
  • MapV2 内部部件：MoveAndResize（允许 Move 与 Resize）。
  • 只读装饰部件：None（不允许任何操作）。
