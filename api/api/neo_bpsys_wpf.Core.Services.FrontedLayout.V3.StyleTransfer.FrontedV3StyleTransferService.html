v3 前台控件 StyleTransfer 核心服务，执行父-子继承与同 peer 传播。

public sealed class FrontedV3StyleTransferService
Inheritance
object
FrontedV3StyleTransferService

Remarks

该服务替代旧链路中 MapV2/GlobalScore 的手写 StyleTransfer 特判：

  • Peer 传播（替代 ApplyMapV2DisplayStyleToAll/CopyMapV2DisplayStyle）：仅匹配完全相同的 CanonicalControlType。
  • Parent-Child 继承（替代 ApplyParentStyleToGlobalScoreCells/ClearGlobalScoreCellStyleOverrides）：根据相同 OptionsPath 匹配父子属性。

不可破坏的传播约束：

  • 默认仅传播 Appearance 语义的属性。
  • RootSize/PartLayout/Behaviors/Effects 只有 profile 显式开启时才传播。
  • DataIdentity 和 Other 永远不传播（数据身份字段、MapKey、TeamType、BindingPath、ControlName 等）。
  • 根级保留字段（Left/Top/ZIndex 等）不会注册为属性，因此不在传播范围内。

ParentFallback 动态读取：ReadValueWithInheritance(FrontedV3PropertyDefinition, FrontedControlConfigBase, FrontedControlConfigBase?, FrontedV3PropertyDefinition?) 每次调用时动态判断子控件是否有 override， 不缓存 fallback 值。父控件后续修改会反映到子控件的读取结果。

Remarks

匹配规则：对每个子控件属性，在父属性列表中查找 OptionsPath 完全相同的父属性， 将父属性的值（通过父存储在父 Config 上读取）写入子属性（通过子存储在子 Config 上写入）。

传播范围：只传播同时满足以下两个条件的属性：

  • 属性语义被 profile 选中（ShouldTransfer(FrontedV3PropertySemantic)）。
  • 子属性不在 LockedToParent 模式（该模式拒绝写入）。

DataIdentity 和 Other 语义的属性不会被 profile 选中，因此永远不会传播。

Remarks

清除规则：对每个子控件属性，当满足以下条件时将值设为 null：

  • 继承模式为 ParentFallback 或 LockedToParent。
  • 属性语义被 profile 选中。

清除后，ReadValueWithInheritance(FrontedV3PropertyDefinition, FrontedControlConfigBase, FrontedControlConfigBase?, FrontedV3PropertyDefinition?) 读取子控件属性时将回退到父值。 对于不可清空（非 nullable CLR 属性）的存储，清除操作为 no-op。

按继承模式解析后的属性值。

Remarks

继承模式处理规则：

  • None：直接读取子控件值。
  • ParentFallback：先读取子控件 override；override 为 null 时动态回退到父控件同 OptionsPath 的值。不缓存 fallback。
  • CopyFromParentOnCreate：创建后独立，直接读取子控件值。
  • LockedToParent：始终返回父控件的值（当父控件或父属性缺失时回退到子控件值）。

TransferPeerStyle(FrontedV3ControlRegistration, FrontedControlConfigBase, IReadOnlyList<PeerStyleTarget>, FrontedV3StyleTransferProfile?)

Remarks

精确匹配约束：只匹配完全相同的 CanonicalControlType。 plugin:a/TeamCard 不能传播给 plugin:b/TeamCard。 当 peer 的 CanonicalControlType 与源不同时，抛出 ArgumentException。

传播范围：只传播同时满足以下两个条件的属性：

  • 属性语义被 profile 选中。
  • 属性语义被源注册的 StyleTransfer 能力允许。
DataIdentity 和 Other 永远不会被传播。

传播方式：源与 peer 使用相同的注册（因此有相同的属性列表与存储访问器）， 通过 GetValue(FrontedControlConfigBase) 读取源值，再通过 SetValue(FrontedControlConfigBase, object?) 写入每个 peer。

Exceptions

ArgumentException

当某个 peer 的 CanonicalControlType 与源不完全相同时抛出。
