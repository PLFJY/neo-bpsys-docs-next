PartCollection 的已解析定义，描述集合的标识、策略、项能力、集合访问方式与模板补齐逻辑。

public sealed class FrontedV3PartCollectionDefinition
Inheritance
object
FrontedV3PartCollectionDefinition

Remarks

PartCollection 是控件内部可变子项集合的抽象（如 GlobalScoreRow 的 Cells）。 与固定 FrontedV3PartDefinition 不同，PartCollection 的项数可变（受 Strategy 约束）， 每个项通过 ItemKeySelector 获取唯一键，几何值通过 CollectionGetter 返回的列表项上的属性读写。

Strategy 决定增删与模板补齐行为：

  • FixedTemplate：通过 EnsureTemplateItems 补齐缺失项，拒绝增删。
  • Dynamic：允许增删，不补齐。
  • ReadOnly：只读。

ItemCapabilities 决定 Designer 中对单个集合项允许的几何操作类型； IFrontedV3GeometryTarget 实现必须遵守能力约束。

集合项的几何值直接读写列表项上的 CLR 属性（如 X/Y/Width/Height）， 不改变 JSON 结构，继续使用现有字段。

Properties

ApplyTemplate

获取或设置根据控件自身模板（如 BO3/BO5、列表项间距等）重新分配集合项位置/可见性的回调； 为 null 时表示该集合不支持模板分配。

public Func<FrontedControlConfigBase, FrontedV3TemplateContext, bool>? ApplyTemplate { get; set; }

Property Value

Func<FrontedControlConfigBase, FrontedV3TemplateContext, bool>

Remarks

这是通用机制，控件可通过此回调暴露"按模板重新分配布局"能力。 回调接收父控件 Config 与 FrontedV3TemplateContext，由控件自身实现决定如何分配位置与可见性。

例如 GlobalScoreRow 在此回调中调用 AutoArrangeBySpacing(FrontedControlConfigBase, bool) 与可见性模板方法，按 CurrentBoModeState 或 TemplateId 指定的模板重新分配 Cell 的 X/Y 与 Visibility。

该回调只负责位置/可见性的模板分配，不修改外观属性（Color/FontFamily 等）。 回调返回 true 表示发生了修改；false 表示无变更。

Designer 在选中根控件且该回调非 null 时显示"按模板重新分配"按钮： 当 Templates 非空时按模板逐个渲染；否则渲染单一通用按钮（无 TemplateId）。

ItemPropertiesFactory

获取或设置集合项外观属性的工厂；为 null 时表示集合项仅支持几何编辑。

public Func<string, IReadOnlyList<FrontedV3PropertyDefinition>>? ItemPropertiesFactory { get; set; }

Property Value

Func<string, IReadOnlyList<FrontedV3PropertyDefinition>>

Remarks

当 PartCollection 集合项在 Designer 中被选中时， BuildCollectionItemSelection(FrontedControlDesignItem, string, string, Action?) 会将几何属性（X/Y/Width/Height）与该工厂返回的外观属性合并， 作为选中目标的 Properties 返回。

工厂参数 itemKey 为选中集合项的唯一键（仅在选中时确定）， 工厂返回的 FrontedV3PropertyDefinition 必须使用 FrontedV3Storage.CollectionItemProperty 绑定到该 itemKey 对应的集合项 CLR 属性。

采用工厂而非预构建列表的原因：FrontedV3Storage.CollectionItemProperty 在构造时即需要 itemKey 参数，而 itemKey 仅在 Designer 选中具体集合项时才确定。 工厂模式将 Storage 构造延迟到选中时，避免引入额外描述类型。

默认 null 表示集合项只支持几何编辑。

Templates

获取或设置该集合支持的具名布局模板列表（如 BO3、BO5、Default、Compact）； 为空列表时 Designer 渲染单一通用"按模板重新分配"按钮，由控件基于 CurrentBoModeState 决定具体模板。

public IReadOnlyList<FrontedV3LayoutTemplate> Templates { get; set; }

Property Value

IReadOnlyList<FrontedV3LayoutTemplate>

Remarks

非空列表时 Designer 不再渲染通用按钮，而是为每个 FrontedV3LayoutTemplate 渲染独立按钮， 用户点击后调用 ApplyTemplate 并通过 TemplateId 传递被点击模板的 Id。

列表为空但 ApplyTemplate 非 null 时， Designer 渲染单一通用按钮，TemplateId 为 null。

默认为空列表，控件无需显式声明具名模板即可使用基于 BO 状态的默认行为。
