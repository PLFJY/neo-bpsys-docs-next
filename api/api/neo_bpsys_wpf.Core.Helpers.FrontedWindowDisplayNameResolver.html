解析前台窗口注册的显示名称。

FrontedWindowDisplayNameResolver

Remarks

Core 层只提供基于 DisplayName / LocalId 的回退显示名。内置窗口的本地化显示名由 UI 层通过现有 resx（Designer.Window.{LocalId}）覆盖。
