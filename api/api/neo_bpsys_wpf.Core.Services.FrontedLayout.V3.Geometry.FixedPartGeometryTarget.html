固定 Part 的几何操作目标，将 Designer 的 Move/Resize 通过 Part 的 Storage 写入 Config。

public sealed class FixedPartGeometryTarget : IFrontedV3GeometryTarget
Inheritance
object
FixedPartGeometryTarget
Implements
IFrontedV3GeometryTarget

Remarks

该实现遵守 FrontedV3PartCapabilities 约束：

  • CanMove 为 false 时 MoveTo(double, double) 不写入。
  • CanResize 为 false 时 ResizeTo(double, double, double?, double?) 不写入。

几何值通过 Part 的 WidthStorage/HeightStorage/ XStorage/YStorage 读写到 Config， 不直接操作 Visual 的 Width/Height。存储访问器为 null 时该维度不持久化。

坐标相对于父 Control：Left/Top 返回 Part 相对于父 Control 的坐标， 而非 Canvas 绝对坐标。

Remarks

该方法不修改 geometry，而是返回一个新的 FrontedV3PartGeometry。 约束规则：

  • X 不小于 0，不大于 parentWidth - width（当 width 有值时）。
  • Y 不小于 0，不大于 parentHeight - height（当 height 有值时）。
  • Width 不大于 parentWidth - X。
  • Height 不大于 parentHeight - Y。
