Remarks

Options 视图是运行时与 Designer 的属性投影，不进入 JSON，不缓存独立值： 读取属性时调用 GetValue(FrontedControlConfigBase)； 修改属性时调用 SetValue(FrontedControlConfigBase, object?) 并触发 PropertyChanged，使 WPF 绑定立即更新视觉。

视图按 OptionsPath 的段分层组织： Appearance.TextColor 在根视图暴露 Appearance 子视图，子视图再暴露 TextColor 叶子属性。 WPF 绑定 {Binding Appearance.TextColor} 通过 ICustomTypeDescriptor 发现这些动态属性。

单一事实来源：Options 的任何属性都直接映射到当前 Config 的根级字段，Options 不保存副本。
