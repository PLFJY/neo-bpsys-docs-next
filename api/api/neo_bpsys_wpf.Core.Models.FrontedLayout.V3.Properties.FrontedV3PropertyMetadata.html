Remarks

当 DefaultValueFactory 非 null 时，工厂优先级高于本字段。

默认值仅在通过 CreateDefaultConfig 创建新控件时写入一次，之后由用户编辑覆盖； 它不参与运行时回退逻辑（运行时回退由 Storage 访问器与 Options 视图决定）。

Inheritance

属性的继承模式，决定子控件如何从父控件获取该属性的值。 默认 None（不继承）。

public FrontedV3PropertyInheritance Inheritance { get; init; }

Property Value

FrontedV3PropertyInheritance

Remarks

继承模式影响 FrontedV3StyleTransferService 的读取与写入行为：

  • ParentFallback：动态读取，子项 override 优先，否则回退到父值。
  • LockedToParent：锁定到父值，拒绝 override。
  • CopyFromParentOnCreate：创建时从父复制，之后独立。

属性的语义分类，决定该属性是否参与 StyleTransfer 传播以及传播时的行为。 默认 Other（不参与传播）。

Remarks

语义分类是 StyleTransfer 的核心驱动：

  • Appearance：默认传播。
  • DataIdentity：永不传播。
  • RootSize/PartLayout/ Behaviors/Effects：仅当 profile 开启时传播。
