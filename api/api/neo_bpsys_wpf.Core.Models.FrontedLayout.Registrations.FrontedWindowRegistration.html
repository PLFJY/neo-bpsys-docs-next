Remarks

Id 是 Canonical ID：内置窗口等于 LocalId； 插件窗口为 plugin:{PackageId}/{LocalId}。Kind 由派生类固定返回。 该基类不承载窗口 CLR 类型或布局资源信息，这些由派生类按承载方式分别提供。 来源分组（BuiltIn / Plugin / External）由 UI 层基于 IsBuiltIn 与 PackageId 推导；顺序使用 DI 注册顺序或在 UI 按 LocalId 排序； 内置显示名由 UI 层通过现有 resx（Designer.Window.{LocalId}）解析。
