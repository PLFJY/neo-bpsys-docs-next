v3 前台控件属性的传播能力配置，描述哪些语义分类可以参与 StyleTransfer 传播。

Remarks

该配置是能力声明（capability），描述控件允许哪些语义被传播。 实际传播时还需配合 FrontedV3StyleTransferProfile（每次操作的传播选择）， 只有能力允许且 profile 选中的语义才会真正传播。

不可破坏的约束：DataIdentity 永远不可传播， 无论 profile 如何设置。传播数据身份字段会导致控件指向错误的数据源。

根级保留字段（Left/Top/ZIndex 等）由 FrontedV3ReservedFields 管理， 不会注册为属性，因此不需要在传播能力中排除。
