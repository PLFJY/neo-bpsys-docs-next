Remarks

该分类是 FrontedV3PropertySemantic 的补充：Semantic 决定属性是否参与传播， 而 Component 决定属性属于哪个样式组件（字体、颜色、边框等），便于未来实现基于组件的细粒度传播控制。

Phase 5 的核心传播逻辑基于 FrontedV3PropertySemantic， FrontedV3StyleComponent 作为元数据附加到属性上，供 Designer UI 分组和未来扩展使用。
