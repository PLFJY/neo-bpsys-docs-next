按模板重新分配集合项布局时由 Designer 提供给控件回调的上下文。

public sealed class FrontedV3TemplateContext
Inheritance
object
FrontedV3TemplateContext

Remarks

该上下文为 ApplyTemplate 回调提供 Designer 侧信息， 让控件可以根据当前编辑状态（例如 BO3/BO5）或被点击的具名模板决定如何重新分配子项位置与可见性。

上下文携带的字段：

  • Services：DI 服务提供器，控件可解析 ISharedDataService 等运行时服务。
  • CurrentBoModeState：当前正在编辑的 BO 状态（BO3/BO5）。控件据此选择对应模板。
  • WindowTypeName：当前编辑的窗口类型名（如 BpWindow）。
  • CanvasName：当前编辑的 Canvas 名称。
  • Document：当前 Designer 文档实例，控件可读取 Canvas 配置、其他控件等信息。
  • TemplateId：当 Templates 非空且用户点击了具名模板按钮时， 该字段为被点击模板的 Id；否则为 null，控件应回退到基于 CurrentBoModeState 的默认模板。

回调只负责位置/可见性的模板分配，不修改外观属性（Color/FontFamily 等）。
