Remarks

该特性由 FrontedV3ControlRegistryExtensions.AddFrontedV3Control<TControl> 在注册时读取，用于生成控件的 Canonical Control Type：

  • 内置控件（IsBuiltIn 为 true）：直接使用 ControlId，例如 Text。
  • 插件控件：使用 plugin:{PackageId}/{ControlId}，例如 plugin:plfjy.ExamplePlugin/TeamCard。

ControlId 只接受安全的局部标识：非空、非纯空白，且不含 /、\、:， 也不允许直接传入完整的 canonical ID（plugin:package/control 形式）。 不同插件可以复用相同的 ControlId。

IsBuiltIn 仅供宿主注册代码使用。插件在插件初始化作用域内设置 IsBuiltIn 为 true 会被拒绝，插件控件无法通过该标记逃离自己的命名空间。

Designer 展示元数据（DisplayNameKey、DescriptionKey、Icon、 DefaultWidth、DefaultHeight、DisplayOrder） 由 Attribute 直接声明，注册时通过 FrontedV3ControlRegistryExtensions.BuildMetadata 推导为 FrontedV3ControlMetadata 暴露到 Registration。 所有元数据字段可选，缺失时由调用方按合理默认值回退。

Remarks

默认为 false。仅声明 SupportsPeerStyleTransfer 为 true 的控件在 Designer 属性面板中可见"应用到同类型控件"按钮， 并可参与同类型 peer 之间的外观样式传播。

业务上目前仅 MapV2Display 内置控件需要此入口；其他内置控件与插件控件 不应设置该属性，按钮不出现。
