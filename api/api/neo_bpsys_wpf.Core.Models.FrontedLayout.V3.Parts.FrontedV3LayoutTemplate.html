Class FrontedV3LayoutTemplate

neo_bpsys_wpf.Core.Models.FrontedLayout.V3.Parts

neo-bpsys-wpf.Core.dll

描述一个具名布局模板（如 BO3、BO5、Default、Compact）， 由控件在 Templates 中声明， 供 Designer 在属性面板渲染为独立的"按模板重新分配"按钮。

public sealed class FrontedV3LayoutTemplate
Inheritance
object
FrontedV3LayoutTemplate

Remarks

当 Templates 非空时，Designer 将不再渲染单一通用按钮， 而是为每个模板渲染一个按钮，点击后调用 ApplyTemplate 并通过 TemplateId 传递被点击模板的 Id。

当 Templates 为空但 ApplyTemplate 非 null 时， Designer 渲染单一通用按钮，点击后调用回调且 TemplateId 为 null，控件应回退到基于 CurrentBoModeState 的默认模板。
