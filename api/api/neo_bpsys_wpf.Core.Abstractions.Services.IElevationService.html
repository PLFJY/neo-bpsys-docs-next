进程权限（UAC 提升级别）检测服务。

public interface IElevationService

Remarks

用于判断当前主程序是否以管理员权限运行。 跨进程 API Hook（如 SetWindowsHookEx 注入到更高权限的进程） 要求钩子进程与目标进程具有相同的完整性级别， 若主程序未提权而目标游戏已提权，注入将失败（ERROR_ACCESS_DENIED）。

Properties

IsCurrentProcessElevated

获取当前进程是否以管理员权限运行（已提升 UAC）。

bool IsCurrentProcessElevated { get; }

Property Value

bool

已提升权限返回 true；普通用户返回 false。

Remarks

权限级别在进程启动时确定，运行期间不会变化，因此此值在进程生命周期内保持不变。

Methods

RestartAsAdmin()

以管理员权限（UAC 提升）重启主程序。

bool RestartAsAdmin()

Returns

bool

是否成功发起重启流程；用户在 UAC 提示中拒绝提权时返回 false。

Remarks

调用此方法后，当前进程会在释放单实例互斥锁并启动新进程后退出。 仅在 IsCurrentProcessElevated 为 false 时调用才有意义； 已提权时调用此方法应直接返回 true 而无需重启。
