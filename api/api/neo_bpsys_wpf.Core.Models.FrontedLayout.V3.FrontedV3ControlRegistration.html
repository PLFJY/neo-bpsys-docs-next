v3 前台控件的注册信息，由统一 Registry 按 CanonicalControlType 索引。

public sealed class FrontedV3ControlRegistration
Inheritance
object
FrontedV3ControlRegistration

Remarks

该类型统一了内置控件与插件控件的身份与元数据。 Registry 只维护 CanonicalControlType → FrontedV3ControlRegistration。

身份规则：

  • 内置控件：CanonicalControlType 直接使用 LocalControlId，例如 Text。
  • 插件控件：CanonicalControlType 为 plugin:{PackageId}/{LocalControlId}，例如 plugin:plfjy.ExamplePlugin/TeamCard。

Property Value

IReadOnlyList<FrontedV3PartDefinition>

Remarks

插件控件通过 FrontedV3Part.Register<TControl> 声明固定 Part， 框架在注册时通过 Discover(Type) 反射发现并转换为 FrontedV3PartDefinition。

内置控件（如 BorderedImage、MapV2Display）通过 BuiltInPartDefinitionResolver 在注册时填充，无需在控件类上声明静态字段。

Designer 选择 Part 时优先从该字段查找，确保插件 Part 与内置 Part 走统一链路。 默认为空列表，表示控件无可编辑的固定 Part。

FrontedV3PropertyTransfer

Remarks

默认为 Default（仅 Appearance 可传播）。 实际传播时还需配合 FrontedV3StyleTransferProfile（每次操作的选择）， 只有能力允许且 profile 选中的语义才会真正传播。

DataIdentity 永远不可传播，无论能力声明如何设置。

SupportsPeerStyleTransfer

是否在 Designer 中显示"应用到同类型控件"按钮并允许同类型 peer 之间传播外观样式。

public bool SupportsPeerStyleTransfer { get; init; }

Property Value

bool

Remarks

默认为 false。该字段由 Registry 在注册时从 FrontedV3ControlAttribute.SupportsPeerStyleTransfer 复制而来，用于在 Designer 中门控同类型 peer 样式传播入口的可见性与可用性。

仅当该字段为 true 时，Designer 才会显示"应用到同类型控件"按钮； 按钮的启用还需满足存在同类型 peer 等其他条件。
