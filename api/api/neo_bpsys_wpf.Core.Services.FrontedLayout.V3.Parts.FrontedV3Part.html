Class FrontedV3Part

Namespace
neo_bpsys_wpf.Core.Services.FrontedLayout.V3.Parts

neo-bpsys-wpf.Core.dll

v3 前台控件固定 Part 的声明，作为控件类上的 public static readonly 字段使用。

public sealed class FrontedV3Part
Inheritance
object
FrontedV3Part

Remarks

典型用法： 

public static readonly FrontedV3Part LogoPart =
    FrontedV3Part.Register<TeamCardControl>("Logo")
        .WithSize(
            FrontedV3Storage.ClrProperty("LogoWidth"),
            FrontedV3Storage.ClrProperty("LogoHeight"))
        .WithCapabilities(FrontedV3PartCapabilities.Resize);

框架在注册控件时通过反射发现这些字段，转换为 FrontedV3PartDefinition。
