object
FrontedV3BuiltInControlRegistryExtensions

Remarks

与插件使用的 AddFrontedV3Control<T> 不同，内置控件使用强类型 Config （如 TextFrontedControlConfig），属性 Schema 通过 neo_bpsys_wpf.Core.Services.FrontedLayout.V3.Properties.BuiltInPropertyDefinitionResolver 从 Config CLR 属性自动发现。

内置控件的 Canonical Control Type 为裸 ControlId（无 plugin: 前缀）， 与 Config 的 ControlType 字段完全一致，JSON 契约不变。

Type Parameters

控件类型，必须继承 FrontedV3ControlBase 并标注 FrontedV3ControlAttribute（IsBuiltIn = true）。

TConfig

控件配置类型，必须继承 FrontedControlConfigBase 并具有无参构造函数。

Exceptions

FrontedLayoutConfigException

当控件类型缺少 FrontedV3ControlAttribute、 未设置 IsBuiltIn、在插件作用域内调用、ControlId 不合法、Part/PartCollection Id 非法或重复、 Part Capabilities 与 Storage 配对不一致、或 PartCollection 策略/Templates 与回调配对不一致时抛出。
