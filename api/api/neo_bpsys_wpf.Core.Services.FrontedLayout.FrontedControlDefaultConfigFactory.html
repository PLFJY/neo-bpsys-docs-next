为设计器 v3 添加控件创建安全的内存默认配置。

FrontedControlDefaultConfigFactory

Remarks

通过 IFrontedV3ControlRegistry 解析 FrontedV3ControlRegistration， 调用 Registration 的 CreateDefaultConfig 创建默认配置。 不再维护硬编码白名单或类型 switch。
