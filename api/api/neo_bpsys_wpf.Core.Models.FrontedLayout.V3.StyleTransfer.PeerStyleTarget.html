PeerStyleTarget

Remarks

该类型用于 TransferPeerStyle(FrontedV3ControlRegistration, FrontedControlConfigBase, IReadOnlyList<PeerStyleTarget>, FrontedV3StyleTransferProfile?)， 描述每个 peer 目标的注册（用于校验 CanonicalControlType 匹配）与配置（作为写入目标）。

精确匹配约束：peer 的 Registration.CanonicalControlType 必须与源完全相同。plugin:a/TeamCard 不能作为 plugin:b/TeamCard 的 peer。
