操作当前赛事 Score System v2 比分状态的服务。

public interface IMatchScoreService

Remarks

服务本身不持有权威比分数据；权威状态来自 CurrentGame 的 MatchScore。它负责按当前 GameProgress、BO3/BO5 模式和实时阵营映射， 将半场赛果写入 v2 状态并刷新派生显示字段。
