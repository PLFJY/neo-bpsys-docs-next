PartCollection 的策略，决定集合项的增删与模板补齐行为。

FrontedV3PartCollectionStrategy

Remarks

三种预设策略：

  • FixedTemplate：根据业务模板补齐缺失项，拒绝任意增删；可移动、缩放、编辑。
  • Dynamic：允许任意增删集合项。
  • ReadOnly：只读，不允许增删或几何操作。

典型用法：

  • GlobalScoreRow 的 Cells：FixedTemplate（BO3/BO5 模板补齐，拒绝增删）。
  • 动态图层列表：Dynamic。
  • 只读装饰集合：ReadOnly。
