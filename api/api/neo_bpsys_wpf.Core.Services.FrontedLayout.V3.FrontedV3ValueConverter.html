v3 前台控件属性值的类型转换器，统一处理存储原始值到目标 PropertyType 的转换。

Remarks

支持以下转换路径：string、bool、int/double、enum、nullable、Color 字符串、JsonElement 到目标类型。

该转换器是无状态静态工具，由 FrontedV3PropertyDefinition 在读写 Config 时调用，确保 ExtensionData 中的 JsonElement 能正确还原为强类型值。

Remarks

该方法统一处理 PropertyGrid 编辑提交、Storage 读写与 Options 代理的值转换， 避免调用方各自调用 Convert(object?, Type) 后再捕获异常判断失败。

支持以下转换路径：

  • null → nullable 目标类型（返回 true 与 null）。
  • JsonElement → 任意目标类型（与 Convert(object?, Type) 路径一致）。
  • 已是目标类型或可分配类型 → 原样返回。
  • enum 目标类型：支持 string 名字解析与 int/long/底层值转换。
  • System.Windows.Media.Color/System.Windows.Media.Brush 字符串解析。
  • string 目标类型：调用 object.ToString()。
  • 其他 IConvertible 类型：通过 ChangeType(object, Type, IFormatProvider) 转换。
