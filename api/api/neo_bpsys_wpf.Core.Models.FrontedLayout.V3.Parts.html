Namespace neo_bpsys_wpf.Core.Models.FrontedLayout.V3.Parts

Classes

FrontedV3LayoutTemplate

描述一个具名布局模板（如 BO3、BO5、Default、Compact）， 由控件在 Templates 中声明， 供 Designer 在属性面板渲染为独立的"按模板重新分配"按钮。

FrontedV3PartCapabilities

固定 Part 的操作能力，决定 Designer 中允许对该 Part 执行的几何操作类型。

FrontedV3PartCollectionDefinition

PartCollection 的已解析定义，描述集合的标识、策略、项能力、集合访问方式与模板补齐逻辑。

FrontedV3PartCollectionPropertyContext

PartCollection 集合项的属性编辑上下文，携带集合定义、关联 Config 与当前项键，供 Designer 属性网格使用。

FrontedV3PartCollectionStrategy

PartCollection 的策略，决定集合项的增删与模板补齐行为。

FrontedV3PartDefinition

固定 Part 的已解析定义，描述 Part 的标识、存储位置与操作能力。

FrontedV3PartGeometry

固定 Part 的几何信息，坐标相对于父 Control（不是 Canvas 绝对坐标）。

FrontedV3PartPropertyContext

固定 Part 的属性编辑上下文，携带 Part 定义与关联 Config，供 Designer 属性网格使用。

FrontedV3Parts

v3 前台控件 PartCollection 的声明，作为控件类上的 public static readonly 字段使用。

FrontedV3TemplateContext

按模板重新分配集合项布局时由 Designer 提供给控件回调的上下文。
