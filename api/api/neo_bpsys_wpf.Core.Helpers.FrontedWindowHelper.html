Parameters

windowType FrontedWindowType

内置窗口类型枚举。

Returns

string

v3 内置窗口返回枚举名（例如 BpWindow）； ScoreWindow 返回 Empty 的字符串形式（复合操作，非真实窗口）。

Remarks

v3 内置窗口的 Canonical ID 直接使用枚举名。 ScoreWindow 是复合操作标识，前台窗口服务 在 Show/Hide 入口对 ScoreWindow 做组合分派，不会用此返回值查找注册。
