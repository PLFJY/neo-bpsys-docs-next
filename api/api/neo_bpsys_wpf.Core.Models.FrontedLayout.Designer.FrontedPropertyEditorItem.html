IsEditingDisabled

指示该行的编辑器控件是否完全禁用交互（IsEnabled=false）。

public bool IsEditingDisabled { get; set; }

Property Value

bool

Remarks

与 IsReadOnly 的区别：IsReadOnly 主要针对文本输入（光标可进入但不可修改）， 而 IsEditingDisabled 通过 IsEnabled=false 完全禁用编辑器（包括 ComboBox/CheckBox/ColorPicker 等）。 典型场景：子控件属性"跟随父控件"时，编辑器应完全禁用，仅显示从父控件继承的值。
