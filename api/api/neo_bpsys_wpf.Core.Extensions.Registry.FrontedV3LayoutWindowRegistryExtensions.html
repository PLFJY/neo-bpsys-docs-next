Remarks

该扩展在插件初始化作用域（neo_bpsys_wpf.Core.Services.Registry.FrontedPluginRegistrationContext）内被调用时， 会自动读取当前插件包 ID 并据此生成 Canonical ID。

Parameters

services IServiceCollection

服务容器。

windowId string

提供方内部的局部窗口标识，必须通过 FrontedV3LayoutWindowIdValidator 验证。

isBuiltIn bool

是否为宿主内置窗口。内置窗口不要求 PackageId， Canonical ID 直接使用 windowId。

Remarks

当在插件初始化作用域内调用时，PackageId 取自 neo_bpsys_wpf.Core.Services.Registry.FrontedPluginRegistrationContext.CurrentPackageId，Canonical ID 为 plugin:{PackageId}/{windowId}。

当 isBuiltIn 为 true 或当前不在任何插件作用域内 （PackageId 为 null）时，按"非插件宿主直接注册"语义处理， Canonical ID 为 windowId，PackageId 为 null。

来源分组（BuiltIn / Plugin / External）由 UI 层基于 IsBuiltIn 与 PackageId 推导；顺序使用 DI 注册顺序或在 UI 按 LocalId 排序；内置窗口的本地化显示名由 UI 层通过现有 resx（Designer.Window.{LocalId}）解析，显示名默认回退到 windowId。

Exceptions

ArgumentException

当 windowId 不是合法的局部窗口标识 （含 null、空串、纯空白、路径分隔符、..、plugin: 前缀等）， 或当前插件包 ID 不是安全的 canonical path segment 时抛出。
