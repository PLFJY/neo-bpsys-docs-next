Class SevenZipArchiveService

Namespace
neo_bpsys_wpf.Core.Services.Archives
Assembly
neo-bpsys-wpf.Core.dll

基于官方 x64 7z.exe 的运行时归档服务,支持 ZIP 和 7z 包。 所有进程调用通过 neo_bpsys_wpf.Core.Services.Archives.SevenZipProcessRunner 启动,支持 CancellationToken 和原生进度汇报。
