Remarks

该基类继承自 System.Windows.Controls.UserControl，因此支持 XAML 声明式视觉树，也支持在代码中构建视觉树。 控件在创建后由宿主通过 InitializeFrontedV3(FrontedV3ControlContext) 注入运行时上下文， 控件通过 Context 访问服务、共享数据、资源解析器与当前配置。

控件 不管理自身的 Canvas 坐标（Left/Top/Width/Height/ ZIndex/Visibility/GaussianBlur），这些由 FrontedV3ControlHost 统一负责。控件只负责矩形区域内的视觉内容。

DataContext 命名空间约定：基类在 InitializeFrontedV3(FrontedV3ControlContext) 中将 FrameworkElement.DataContext 统一设置为完整的 FrontedV3ControlContext， 派生控件无需自行设置 DataContext。XAML 与代码绑定应通过 Options.* 根命名空间访问 V3 属性， 例如 {Binding Options.Appearance.TextColor}，以明确隔离 WPF 自带属性与 V3 注册属性， 避免误绑定到 FrameworkElement 的内建属性。

属性编辑通过 Options 动态代理视图完成：XAML 绑定 {Binding Options.Appearance.TextColor} 最终委托到对应 FrontedV3PropertyDefinition 的 Storage 访问器， 读写直接作用于当前 FrontedControlConfigBase，不缓存独立值。
