v3 前台控件属性的存储访问器，负责从 FrontedControlConfigBase 读取或写入单个属性值。

public interface IFrontedV3StorageAccessor

Remarks

存储访问器是属性定义（FrontedV3PropertyDefinition） 的一部分，与 OptionsPath 解耦：OptionsPath 是 Designer 属性网格与 StyleTransfer 使用的逻辑路径， 而存储访问器决定值在 Config 上的实际读写位置（根级 CLR 属性或 ExtensionData 字典键）。

存储访问器不得覆盖根级保留字段（Left/Top/Width/Height/ZIndex/ Visibility/BehaviorGuid/GaussianBlur/ControlType），该校验在注册时由 FrontedV3PropertyDefinition 配合 FrontedV3ReservedFields 完成。

实现应返回"原始"存储值（例如 ExtensionData 中的 JsonElement）， 类型到目标 PropertyType 的转换由 FrontedV3ValueConverter 统一处理。

Remarks

对于 ExtensionData 存储，该值为字典键；对于 CLR 属性存储，该值为属性名。 该值不得为 FrontedV3ReservedFields 中列出的保留字段。
