v3 前台控件 Part Visual 的运行时绑定器，在控件创建后由 Host 调用， 将 Part Storage 中的几何值（X/Y/Width/Height）应用到通过 FrontedV3PartVisualResolver 发现出的 System.Windows.FrameworkElement 上。

public static class FrontedV3PartVisualRuntimeBinder
Inheritance
object
FrontedV3PartVisualRuntimeBinder

Remarks

该绑定器是 Part 系统在 Runtime 的框架级入口，替代插件作者在 OnInitializeFrontedV3 中手写几何读取代码的需要。 调用链为：

  • Resolve(FrameworkElement, IReadOnlyList<FrontedV3PartDefinition>, ILogger?) 发现 PartId → Visual 映射并输出诊断。
  • 本绑定器根据 Part 的 WidthStorage/ HeightStorage/ XStorage/ YStorage 读取 Config 中的几何值并应用到对应 Visual。

FrontedV3PartCapabilities 不影响读取与应用：能力仅约束 Designer 中允许的几何操作类型， Runtime 绑定器无论能力如何都应用 Storage 中已有的值。这是因为绑定器不产生编辑动作， 只是把已持久化的值恢复到视觉。

几何应用规则：

  • Width/Height：当 Storage 返回非 null 值时设置 System.Windows.FrameworkElement.Width/ System.Windows.FrameworkElement.Height；为 null 时保留 XAML 中声明的默认值。
  • X/Y：通过 SetLeft(UIElement, double)/SetTop(UIElement, double) 附加属性设置； 仅当 Visual 的父容器为 System.Windows.Controls.Canvas 时生效，其他容器中附加属性不会产生视觉效果， 但也不会报错。

缺失或重复 Visual 的诊断由 FrontedV3PartVisualResolver 输出，本绑定器原样返回。

public static FrontedV3PartVisualDiscoveryResult Bind(FrameworkElement control, IReadOnlyList<FrontedV3PartDefinition> partDefinitions, FrontedControlConfigBase config, ILogger? logger = null)

Parameters

control FrameworkElement

刚创建并初始化的 v3 控件实例。

该控件声明的 Part 定义列表。

config FrontedControlConfigBase

控件配置实例，作为几何值的单一事实来源。

可选日志，用于记录诊断。

Returns

FrontedV3PartVisualDiscoveryResult

包含已发现 Visual 与诊断的结果；调用方可据此记录日志或显示 Designer 诊断。

Remarks

该方法不抛出 Part 相关异常：发现失败、Visual 缺失、Storage 读取异常等都输出为诊断或日志， 不阻止 Host 完成初始化。这确保插件 Part 声明错误不会让整个控件无法显示。

Exceptions

ArgumentNullException

当 control、 partDefinitions 或 config 为 null 时抛出。
