Remarks

该发现器扫描控件的视觉树与公共属性：

  • XAML：fronted:FrontedV3.PartId="Logo" 附加属性。
  • C#：[FrontedV3PartVisual("Logo")] 特性标注的属性。

两种声明方式解析后映射到同一个 Part。

缺失或重复 Visual 输出诊断（warning），不崩溃 Designer，不破坏 Config：

  • 声明了 Part 但未找到对应 Visual → warning。
  • 多个 Visual 映射到同一 PartId → warning，使用第一个发现的 Visual。

该发现器位于 Core 项目，通过反射读取 PluginSdk 中的 FrontedV3PartVisualAttribute，避免 Core → PluginSdk 的循环引用。
