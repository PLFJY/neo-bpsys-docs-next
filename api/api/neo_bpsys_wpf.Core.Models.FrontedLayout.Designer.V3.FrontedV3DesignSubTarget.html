Remarks

Phase 6 Designer 去特化后，子目标身份不再通过控件专用 selection state（如 SelectedMapV2InternalStylePart、SelectedGlobalScoreCell）维护， 而是统一由 SubTarget 携带。

实现类型：

  • FrontedV3FixedPartTarget：固定 Part 子目标，携带 Part Id。
  • FrontedV3CollectionItemTarget：PartCollection 集合项子目标，携带集合 Id 与项 Key。
