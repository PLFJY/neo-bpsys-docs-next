Remarks

局部控件标识是提供方内部的短控件名（例如 TeamCard 或内置的 Text）， 不应包含路径分隔符、plugin: 前缀形式或任何文件系统非法字符。 不允许直接传入完整的 canonical ID（plugin:package/control 形式）。
