Remarks

染色属于 CPU 像素处理，不应当阻塞前台窗口的 UI 线程。运行时宿主首次渲染同步完成以 避免初始空白，后续颜色/强度/尺寸变化通过调度器合并，并在后台计算后以 latest-wins 方式回到 UI 线程应用；Designer 预览与单元测试默认保持同步，避免破坏既有交互时序。

控件不可见期间只记录脏状态，恢复可见后补算一次，避免被遮挡或最小化的前台窗口持续消耗 CPU。
