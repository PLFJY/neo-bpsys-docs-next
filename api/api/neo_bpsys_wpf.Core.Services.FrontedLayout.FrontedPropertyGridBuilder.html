Remarks

该方法是 Root 控件属性网格的 Schema 驱动路径：属性行由 FrontedV3PropertyDefinition 列表构造，属性值通过 GetValue(FrontedControlConfigBase) 读取，编辑时通过 SetValue(FrontedControlConfigBase, object?) 写入，不通过 propertyName 字符串反射。

身份行（Name、ControlType）和缺失插件诊断行仍由本方法构造，因为它们不属于 Schema 属性。 其余 Config 级属性全部来自 Schema。
