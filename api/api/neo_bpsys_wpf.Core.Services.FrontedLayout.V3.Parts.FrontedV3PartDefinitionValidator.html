校验 FrontedV3PartDefinition 与 FrontedV3PartCollectionDefinition 列表的声明完整性，在控件注册时 fail-fast 阻止非法声明进入 Registration。

object
FrontedV3PartDefinitionValidator

Remarks

该校验器在插件控件注册（AddFrontedV3Control<T>）与内置控件注册 （AddBuiltInFrontedV3Control<TControl,TConfig>）路径中共享调用， 确保两条注册链路对 Part/PartCollection 的约束保持一致。

校验规则：

  • Part Id 与 PartCollection Id 必须非空、非空白、不含路径分隔符或文件系统非法字符。
  • 同一控件内的 Part Id 之间必须唯一（区分大小写）。
  • 同一控件内的 PartCollection Id 之间必须唯一（区分大小写）。
  • Part Id 与 PartCollection Id 之间不得冲突（避免 Designer 选中歧义）。
  • CanMove 为 true 时， XStorage 与 YStorage 不得同时为 null。
  • CanResize 为 true 时， WidthStorage 与 HeightStorage 不得同时为 null。
  • FixedTemplate 策略的 PartCollection 必须配置 EnsureTemplateItems。
  • 声明了具名 Templates 的 PartCollection 必须同时配置 ApplyTemplate。
